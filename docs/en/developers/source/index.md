# Source and dependencies

The [Motara repository](https://github.com/MotaraSoft/Motara) contains the application source. Its published tree omits test projects, build outputs, packaging material, private models, and optional native/runtime artifacts.

A source build uses the .NET SDK selected by global.json. Optional runtime paths are local development inputs. PurismCore is maintained separately under MIT. Other third-party components retain their own terms.

Read the repository's [third-party inventory](https://github.com/MotaraSoft/Motara/blob/main/THIRD-PARTY-NOTICES.md) before preparing a binary package.
