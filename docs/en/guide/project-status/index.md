# Project status

The repository contains source code only. There is no official binary release.

## Included in the source tree

- Avalonia desktop shell with English and Simplified Chinese localization, local settings, structured local logs, menus, and shortcut profiles.
- Local scenes, Cubism model import, image and video backgrounds, signal attachments, effects, and screenshots.
- iFacialMocap UDP, local-camera MediaPipe, and local OpenSeeFace adapters, with mapping, formulas, calibration, filtering, parameter priority, and bounded frame processing.
- MOC3 parsing and Skia rendering through PurismCore, plus a Live2D Cubism Editor external-API output adapter.
- Installation identity storage, invitations, encrypted peer frames, local friend records, and model-package transfer primitives.

## Not provided

- VTube Studio output.
- A public plugin SDK, plugin host, and stable third-party extension contract.
- macOS Keychain and Linux Secret Service implementations for collaboration identity storage.
- An official installer, update flow, release-ready collaboration networking, or end-to-end interoperability.
- Official redistributable runtime packages for PurismCore, FFmpeg, Spout2, NDI, MediaPipe, OpenSeeFace, camera support, and related model data.

APIs, persisted formats, collaboration protocols, network behavior, and supported platforms have no compatibility guarantee.
