# Availability

Some functions require local runtimes, external applications, or model data.

## Local components

The repository has no official redistributable bundle for PurismCore, FFmpeg, Spout2, NDI, MediaPipe, OpenSeeFace, ESCAPI, camera support, or associated model data. Local files can enable the related functions during development. The repository does not grant redistribution rights for those files.

## Distribution status

There is no official binary release or installer. Before making a binary package, identify each included artifact, its version, source, license, and notice requirements.
