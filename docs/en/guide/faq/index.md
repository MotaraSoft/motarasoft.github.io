# FAQ

## Can I download Motara?

There is no official binary release. The [source repository](https://github.com/MotaraSoft/Motara) can be built with the required local dependencies.

## Are tracking frames uploaded automatically?

No. Motara does not automatically upload tracking frames. Collaboration actions can create network connections after you start them; see the [privacy policy](/privacy/).

## Can I redistribute the optional runtimes?

Check each component's terms and the [third-party notices](https://github.com/MotaraSoft/Motara/blob/main/THIRD-PARTY-NOTICES.md). The source repository does not grant redistribution rights for optional runtimes.
