# Motara

Motara is an open-source desktop application for facial-tracking data, virtual-avatar control, and scene composition.

## Workspace

A workspace can contain scenes, local models, tracking inputs, parameter mappings, and a Cubism Editor output target. Their settings are configured together in the desktop application.

The public repository contains the application source. It has no official installer or redistributable runtime bundle. APIs, file formats, collaboration protocols, network behavior, and supported platforms can change with the source.
