# Motara

Motara 是一款开源桌面应用，用于面部捕捉数据处理、虚拟形象控制和场景合成。

## 工作区

一个工作区可以包含场景、本地模型、捕捉输入、参数映射和 Cubism Editor 输出目标。这些设置在桌面应用中统一配置。

公开仓库包含应用源码，暂无官方安装程序和可再分发运行时包。API、文件格式、协作协议、网络行为和支持平台会随源码修改而变化。
