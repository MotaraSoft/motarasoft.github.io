# 隐私政策

更新日期：2026-08-13

本政策适用于 Motara 应用及 www.motara.org 的邀请页。

## 处理的数据

根据你使用的功能，Motara 可能处理摄像头画面、面部或身体捕捉数值、模型和场景文件、截图、本地安装实例身份、好友记录、邀请令牌、点对点协作所需的设备与网络信息，以及诊断日志。除非你发起协作操作，这些数据在本地处理。

## 网络活动

Motara 不会自动上传捕捉帧、模型、场景或截图。打开邀请、加入会话或传输模型包等协作操作，可能在你发起后建立点对点或服务网络连接。

邀请页不会发送、存储、解码或记录令牌，只会在你点击打开按钮后构造本地 motara:// 链接。

## 控制与删除

你可以停止捕捉和协作，删除本地好友与场景，并通过操作系统删除本地应用数据。请不要公开分享邀请 URL；在过期前，URL 中的令牌可能授予相应的邀请能力。

Motara 不出售个人信息。隐私问题请联系 [hello@motara.org](mailto:hello@motara.org)。
