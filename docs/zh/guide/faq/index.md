# 常见问题

## 可以下载 Motara 吗？

当前没有官方二进制发行版。满足本地依赖后可从[源码仓库](https://github.com/MotaraSoft/Motara)构建。

## 捕捉帧会自动上传吗？

不会。Motara 不会自动上传捕捉帧。你发起协作操作后，应用可能建立网络连接；请参阅[隐私政策](/zh/privacy/)。

## 可以再分发可选运行时吗？

请检查每个组件的条款和[第三方声明](https://github.com/MotaraSoft/Motara/blob/main/THIRD-PARTY-NOTICES.zh-CN.md)。源码仓库不授予可选运行时的再分发权。
