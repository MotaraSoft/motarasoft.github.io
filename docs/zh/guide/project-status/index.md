# 项目状态

仓库提供源码，暂无官方二进制发行版。

## 源码已包含

- 带英文与简体中文界面的 Avalonia 桌面外壳、本地设置、结构化本地日志、菜单和快捷键配置。
- 本地场景、Cubism 模型导入、图像和视频背景、信号附件、效果和截图。
- iFacialMocap UDP、本地相机 MediaPipe、本地 OpenSeeFace 适配器，以及映射、公式、校准、滤波、参数优先级和有界帧处理。
- 通过 PurismCore 实现的 MOC3 解析与 Skia 渲染，以及 Live2D Cubism Editor 外部 API 输出适配器。
- 安装实例身份存储、邀请、加密点对点帧、本地好友记录和模型包传输原语。

## 当前未提供

- VTube Studio 输出。
- 公开插件 SDK、插件宿主和稳定的第三方扩展契约。
- 面向协作身份存储的 macOS Keychain 与 Linux Secret Service 实现。
- 官方安装包、更新流程、可发行级协作网络和端到端互操作性。
- PurismCore、FFmpeg、Spout2、NDI、MediaPipe、OpenSeeFace、相机支持组件及相关模型数据的官方可再分发运行时包。

API、持久化格式、协作协议、网络行为和支持平台不提供兼容性保证。
