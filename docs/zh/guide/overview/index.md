# 当前功能

公开源码树包含：

- **场景与模型：** 本地场景持久化、模型分配、图像和视频背景、效果、截图，以及 Cubism 模型目录或压缩包导入。
- **捕捉：** iFacialMocap UDP、本地相机 MediaPipe 和本地 OpenSeeFace 进程适配器，并提供映射、公式、校准、滤波和有界帧处理。
- **渲染：** 通过独立维护、MIT 许可的 [PurismCore](https://github.com/MotaraSoft/PurismCore) 组件实现 MOC3 解析和 Skia 渲染。
- **输出：** 可配置参数映射的 Live2D Cubism Editor 外部 API 适配器。
- **协作：** 安装实例身份存储、邀请格式、加密点对点帧、本地好友记录和模型包传输原语。

部分功能需要本地运行时、外部应用或模型数据。仓库未包含的文件见[可用性](/zh/guide/availability/)。
